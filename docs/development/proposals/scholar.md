## `scholar-1` — A provenance envelope on every reply: snapshot manifest in the table, effective query and edition URL in the text

**survived 3/3, with corrections · effort M · impact 5/5**

**What the code does today.** format_results (packages/kansallisarkisto-lib/src/ra_mcp_kansallisarkisto_lib/dataset.py:446-479) prints only keyword, count and offset — not which filters, match_all or fuzzy were in force, and nothing about which harvest. ## `scholar-2` — Keyword-in-context snippets, 'matched in' attribution, and an explicit text-status per hit

**survived 3/3, with corrections · effort M · impact 5/5**

**What the code does today.** _snippet (formatter.py:255-259) returns the first 400 characters of the transcript regardless of where the term occurs; lancedb returns only _score (dataset.py:309), no highlight. searchable_text (models.py:142-155) folds issuingplace, country, indexterm and language into the index, so untranscribed charters are returned on catalogue matches, but _render_charter (formatter.py:290-296) prints only '(catalogued but not transcribed — no text available)' — a model cannot tell 'Åbo occurs in the text' from 'the catalogue says issued at Åbo'. Spike (b): across 12 queries on the fixture, 34 transcribed hits — the query term is visible in the opening-400 snippet for 25 (74%); a folded-prefix KWIC finds it for 31 (91%); the 4 untranscribed hits matched only in issuingplace/language/indexterm and the reply says nothing about that.

**The gap.** A quarter of transcribed hits show the model a passage that does not contain what it searched for, so it either over-claims from the opening lines or calls df_get_charter for everything. Untranscribed hits invite the worst over-claim: 'DF 670 mentions Åbo' when there is no text at all.

**The proposal.** formatter.py: kwic(text, terms, width=150, max_windows=2) -> list[str] using the same normalisation the index applies (NFKD, strip combining marks, casefold) and prefix matching per term (a Swedish stem is a prefix of the surface form in nearly all cases; for fuzzy>=1 fall back to difflib.SequenceMatcher ratio >= 0.8 on tokens; a quoted phrase matches the folded phrase exactly). Windows are rendered '… ⟦konungh⟧ Cristoffer …' with U+27E6/U+27E7 as markers — characters no record contains, guarded the same way _oneline guards newlines. Per hit add one line: 'matched in: transcript' | 'matched in: catalogue only (issuingplace="Åbo") — no text was searched: untranscribed' | 'term not located in the text shown — matched via stemming or a catalogue field'. Add a text-status token to the header line: 'transcribed (edition text, OCR)' vs 'untranscribed'. The DF transcripts are OCR of printed editions (FMU/REA) with editorial apparatus, not HTR of manuscripts — say that once in the tool description instead of the blanket 'machine-recognised', so the model calibrates. Optionally an ingest-time noise score (single-letter-token ratio, non-alpha-token ratio, omission runs '– – –') stored as a float column and surfaced only when above a threshold (fixture: DF 1 has 27 non-alpha tokens of 346; DF 1215 has 7 single-letter tokens of 218).

**Why it is once-in-a-lifetime.** The model sees exactly where the evidence is and whether there is any. This is the single change that most reduces fabricated readings from a tool that returns text to a language model, and it is computed in Python from data already in the record — no engine change.

**How we would know.** Pinned on the fixture: >= 90% of transcribed hits across the 12-query set render a marked window (today 74% show the term at all); 100% of untranscribed hits name the catalogue field that matched. Corpus-wide the same script reports the ratio and it goes in docs/how-it-works/search-tips.md.

**Risks.** The Python KWIC approximates the tantivy analyser; irregular stems or fuzzy matches will sometimes produce 'not located' — the line must say so honestly. Snippet length grows (two 300-char windows vs one 400-char opening). The noise score is a heuristic and must not be presented as OCR confidence.

**First step.** PR: kwic() + the 'matched in' line + a test that reproduces the 12-query measurement and asserts the marked-window ratio >= 0.9 and the catalogue-attribution ratio == 1.0.

**Spike.** /tmp/claude-0/-home-user-kansallisarkisto-mcp/6ff06e2b-109d-555b-be3f-fc58e4c2ea7f/scratchpad/spike/spike.py section (b): fold+prefix KWIC over fixture hits for ['konung','Åbo','ecclesia','biskop','de','gods','Abo','kirkio','breff','Varjager','Raseborg','dominus'] — prints opening-snippet vs KWIC visibility and, for untranscribed hits, which catalogue field matched.
